# ZYVORA ULTRA X

Premium unified platform for **AI OS + Cyber World + Metaverse + Cloud**.

## Vision
One ZYVORA identity across Web, Android and Desktop, powered by ZYVORA CORE.

## Initial stack
- Web: Next.js + TypeScript
- API: Fastify + TypeScript
- Database: PostgreSQL
- Cache/realtime foundation: Valkey
- Android: Kotlin + Jetpack Compose
- Desktop: Tauri foundation

## Run
```bash
pnpm install
pnpm dev
```

The first milestone focuses on the premium web experience and API foundation. Android/Desktop shells share the same architecture and will connect to ZYVORA CORE in later milestones.
